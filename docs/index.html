Supported syntax and explanation

JavaScript regular expressions support literals, escapes, Unicode escapes, character classes, anchors, boundaries, capturing and non-capturing groups, named groups, alternation, greedy and lazy quantifiers, lookaround, backreferences, and the runtime's supported flags. JavaScript does not support every dialect feature, including possessive quantifiers, atomic groups, conditionals, and subroutines. Unsupported syntax reports a parser error. The preview lists each match, capture groups, replacement text, and elapsed time. Always use bounded input; a pathological expression may consume browser time.
