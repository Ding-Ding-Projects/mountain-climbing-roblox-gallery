    Supported syntax and safety

    This uses the browser's JavaScript RegExp engine and current engine-supported flags. Anchors, character classes, captures, alternation, quantifiers, lookaround, backreferences, and replacement tokens are available when supported by the browser. Unsupported syntax is refused with the browser parser detail. Patterns are limited to 128 characters and sample text to 512 characters. Ambiguous nested repetitions and quantified alternatives are refused before testing to reduce backtracking risk. This bounded check is not a proof that every expression is safe.

    Progress update · 2026-09-29

    Version 99 Bakery pilot and earlier facility views

    The 1,013-part Bakery pilot is applied in Studio version 99. It contains seven supplied doors and 20 markers. The original 538-part interior and earlier 986-part pilot remain preserved, and all 4,003 supplied-original descendants remain untouched. Play started in 10.066 seconds; the runtime binder reached ready in 5.520 seconds with 35 yields and a maximum 6.399 ms slice. One 6.015-second client sample measured 60.012 FPS, with a 17.898 ms p95 frame, a 19.184 ms maximum frame, and no frames above 100 ms. This single sample is not broad performance acceptance. The pilot remains unaccepted: room clearance, individual doors, privacy, service behavior, and save/reopen remain unverified. Studio returned to Edit version 99. Three earlier station and rest construction views are included as historical imagery; none depicts this Bakery pilot.
